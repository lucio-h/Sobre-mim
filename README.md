## ✨ Destaques

- 🎨 Design moderno com **Glassmorphism**
- 🌌 Background dinâmico com **blur, noise e efeitos visuais**
- ⚡ Animações suaves com **IntersectionObserver**
- ⌨️ Efeito de digitação no cargo
- 📱 Layout responsivo
- 🧠 Estrutura organizada e escalável
- 🔥 Interface inspirada em portfólios profissionais

## 🧠 Tecnologias

Este projeto foi desenvolvido utilizando:

- **HTML5** — Estrutura semântica
- **CSS3** — Estilização avançada + animações
- **JavaScript** — Interatividade e manipulação do DOM
- **Font Awesome** — Ícones
- **Google Fonts** — Tipografia moderna
